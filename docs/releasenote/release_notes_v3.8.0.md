## SonderWeb 3.8.0

**Profiles**
- Keep different accounts apart: each profile has its own sign-ins and site data, so a Google account in one profile doesn't show up in another.
- Turn it on in Settings › Profiles › Use profiles. Off (the default), SonderWeb works as it always did.
- With profiles on, your profile picture replaces Home in the bar (tap: start page, hold: switch profile) and sits bottom left on the start page (tap: switch profile).
- Add, rename, recolour, set a picture or delete profiles in Settings › Profiles.
- Choose what each profile keeps to itself: open tabs, history, bookmarks and start page shortcuts can each be separate or shared. Sign-ins are always separate.
- Extensions, settings and downloads are shared. Firefox Sync (SonderWeb Sync) and Copy everything use the first profile.

**Fixes**
- Restoring a uBlock Origin backup: uBlock keeps working after it restarts itself, and backup files are recognised more reliably.
