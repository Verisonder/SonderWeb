## SonderWeb 4.0.0

**Fixes**
- Extension panels scroll: tall ones (like NopeCHA's) no longer get stuck. Swipe the handle at the top down to close a panel.
- Sites behind Cloudflare's security check (like apkmirror.com) load again on networks whose DNS broke the check: normal tabs now use encrypted DNS (Quad9) by default. If you chose a setting yourself, it stays. Your VPN keeps working.
- Private tabs: the picture in the bar no longer opens your profiles. Tapping it asks before going to the start page, so a stray tap can't take you off the page you're on.

**New options**
- Settings › Search › Suggestions: turn Recent sites, History and Bookmarks suggestions on or off.
- Settings › Start page: hide the Shortcuts (with their +) and the Search button at the bottom.

**Change**
- While you type, the page behind the search is darker; the start page goes almost black, so its own search field doesn't show through.
