## SonderWeb 3.9.0

**Profiles are complete**

Keep your accounts apart: each profile has its own sign-ins and site data, so a Google account signed in on one profile never shows up on another.

- **Turn it on:** Settings › Profiles › Use profiles. Off (the default), SonderWeb works as one browser, as always.
- **Switch:** tap your profile picture, in the bar or bottom left on the start page, and pick a profile. Hold the picture in the bar for the start page.
- **Your Google account:** open a Google page and the profile takes that account's picture and name (unless you chose your own).
- **A second account:** sign in to another Google account on the same profile and SonderWeb offers to give it a profile of its own, with Google's sign-in ready there, or to switch to the profile that already has it.
- **Choose what's separate:** open tabs, history, bookmarks and start page shortcuts can each be kept per profile or shared. Sign-ins are always separate.
- **Manage:** add, rename, recolour, set a picture or delete profiles in Settings › Profiles.
- **Private tabs** show a hat-and-glasses picture instead of the profile's.
- Extensions, settings and downloads are shared by all profiles. Firefox Sync (SonderWeb Sync) and Copy everything use the first profile.

**Change**
- Tapping the profile picture in the bar now opens the profile list (it used to go to the start page; hold it for that now).
