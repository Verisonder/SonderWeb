## SonderWeb 1.7.0

**Tabs**
- Inactive tabs: tabs you haven't opened for 14 days, and older copies of a page that's open in another tab, move behind one row at the top of the tab list. Open one, close one, or close them all.
- The tab list opens at the bottom, where the newest tabs are.
- Empty new tabs are no longer listed.
- Holding the tabs button no longer lists the tab you're on.

**Back**
- On a tab a site opened, back closes it and returns to that site instead of the start page.

**Status bar**
- New option under Settings › Appearance › Screen: hide the status bar while scrolling. It shows at the top of a page and on the start page.
