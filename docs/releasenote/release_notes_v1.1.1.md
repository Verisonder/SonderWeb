## SonderWeb 1.1.1

**Downloads**
- A notification while a file downloads: progress, speed and time left, with a Cancel button. When it's done, tap it to open the file.
- The Downloads page shows live progress, size, site and when, with an icon for the kind of file.
- A ⋮ button on each download: open, share, try again, cancel, copy the link, go to the site, remove from the list or delete the file.
- Downloads cut off by closing the app show as failed and can be tried again.

**Address bar**
- When you swipe the bar down, the phone's gesture bar hides too, so the page fills the screen.
