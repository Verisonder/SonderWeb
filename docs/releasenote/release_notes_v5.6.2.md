## SonderWeb 5.6.2

**New**
- Settings › Appearance › Theme › OLED: the dark look on pure black, so black pixels stay off.
- Settings › Start page › Phone's time and battery: the phone's status bar is hidden on the start page (it has its own clock). Turn it on to show it there again; swipe down to peek.
- SonderCircle › Advanced › Opening animation: how long the glow runs when the circle opens (Off to 3 s; 1.1 s as before), with its own Reset to default.

**Changes**
- Clock fonts: the font picker slides up from the bottom like the search, with the clock still in view, so you see each font on the real clock as you tap it.
