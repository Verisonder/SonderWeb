## SonderWeb 1.3.0

**Downloads**
- Downloads keep going when you leave the app or lock the phone.
- The "Downloading…" message has a More button that opens the Downloads page.

**Passkeys**
- Passkeys from your password manager (Proton Pass, Google, Bitwarden…) can now reach sites on Android 14 and newer.

**Settings**
- Default browser works: it asks Android to make SonderWeb your default, or opens the phone's Default apps setting where that question isn't available.
- Checking for updates no longer fails with "GitHub answered 403", and the Check button keeps its size while checking.
